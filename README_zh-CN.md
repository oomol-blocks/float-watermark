# 浮动水印工具

**智能的视频内容保护浮动水印工具**

浮动水印是一个智能的视频处理工具，为您的视频添加动态浮动水印。与容易被移除的静态水印不同，这些水印使用不同的轨迹在视频中自然移动，在防止内容盗用和未经授权使用方面更加有效。

## 🎯 功能介绍

此工具自动为您的视频添加可定制的文本水印，具有以下特点：
- **动态移动** - 在屏幕上以浮动模式移动
- **自然融合** - 与您的内容自然融合，不会过于突兀
- **强力保护** - 有效防止内容盗版和未经授权的传播
- **保持质量** - 在添加安全功能的同时保持视频质量

### 可用模块：浮动水印

该工具的主要组件是**浮动水印**模块，用于处理您的视频并添加浮动水印。

#### 输入要求：
- **视频文件**：您要保护的视频（支持 MP4、MOV、AVI 等常见格式）
- **水印文本**：您要显示为水印的文字
- **输出目录**：您要保存处理后视频的位置

#### 自定义选项：
- **水印数量**：选择要添加多少个浮动水印（1-10个，默认：1个）
- **颜色**：使用颜色选择器选择水印颜色（默认：白色 #FFFFFF）
- **透明度**：调整不透明度从 0.1 到 1.0（默认：0.8，微妙可见）
- **字体大小**：设置文本大小在 8-72 像素之间（默认：40）

#### 输出结果：
- 应用了浮动水印的新视频文件
- 保持原始视频质量和格式
- 可直接用于分发，具有增强的内容保护

## 🎨 水印运动模式

系统自动为每个水印分配不同的运动模式：

- **水平运动**（30% 概率）- 主要水平移动，带有轻微的垂直变化
- **垂直运动**（30% 概率）- 主要垂直移动，带有轻微的水平变化
- **椭圆运动**（40% 概率）- 复杂轨迹，形成自然的椭圆浮动模式

每个水印都有独立的随机种子，确保运动轨迹独特且不重叠。

## ✨ 主要优势

- **🎯 智能浮动**：水印以椭圆、水平和垂直轨迹移动，呈现自然运动效果
- **🎨 高度可定制**：调整文字、颜色、透明度和字体大小以满足您的需求
- **🔢 多水印支持**：同时添加 1-10 个水印，每个都有独立的运动
- **📱 智能适配**：根据视频分辨率自动调整水印位置和安全边距
- **⚡ 高效处理**：基于 FFmpeg 构建，快速处理的同时保持视频质量
- **🛡️ 版权保护**：动态水印更难被移除，有效保护内容版权
